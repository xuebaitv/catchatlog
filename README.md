# 对话展示系统

一个简单的PHP对话展示系统，支持文字和图片显示，包含后台管理功能和分组管理。

## 功能特点

- 📱 响应式设计，支持移动端浏览
- 📷 支持多图片上传和展示
- 📁 **分组功能**：可将对话分配到不同分组
- 🔐 简单的密码验证后台
- 🗑️ 支持对话和分组的添加和删除

## 项目结构

```
html/
├── index.php              # 首页，展示对话列表（按分组显示）
├── admin/
│   ├── login.php          # 后台登录页面
│   └── index.php          # 后台管理页面
├── inc/
│   ├── config.php         # 配置文件
│   └── functions.php      # 工具函数
├── chat/                  # 对话数据存储目录
│   └── groups.json        # 分组数据
└── photos/                # 图片存储目录
```

## 安装说明

1. 将项目文件部署到PHP服务器（如Apache、Nginx）
2. 确保 `chat/` 和 `photos/` 目录有写入权限
3. 默认管理员密码：`admin123`（可在 `inc/config.php` 中修改）

## 使用方法

### 前台展示

访问首页 `index.php` 即可查看所有对话内容，按分组展示。

### 后台管理

1. 访问 `admin/login.php`
2. 输入密码登录后台
3. 在后台可以：
   - 创建/删除分组
   - 添加新对话（支持选择分组和多图片上传）
   - 删除已有对话

## 配置说明

在 `inc/config.php` 中可以修改以下配置：

- `ADMIN_PASSWORD`: 管理员密码
- `CHAT_DIR`: 对话数据存储目录
- `PHOTOS_DIR`: 图片存储目录
- `PHOTOS_URL`: 图片访问URL
- `GROUPS_FILE`: 分组数据文件路径

## 技术栈

- PHP 7.0+
- HTML5
- CSS3
- JavaScript

## 注意事项

1. 确保服务器支持PHP文件上传功能
2. 建议在生产环境中修改默认密码
3. 删除分组会同时删除该分组下的所有对话
4. 定期清理不需要的图片文件
