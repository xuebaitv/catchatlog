# 💬 对话展示系统

一个功能完善的PHP对话展示系统，模拟微信式左右对话气泡，支持文字和图片显示，包含完整的后台管理功能、分组管理、瀑布流布局、前端搜索、**AI智能话术推荐**等强大功能。

## ✨ 功能特点

### 🎨 前端展示

- 💬 **微信式气泡布局**：客户消息左对齐，我的消息右对齐
- 🌊 **瀑布流卡片布局**：CSS Columns 实现智能瀑布流，高度自适应
- 🎯 **分组导航栏**：顶部导航快速跳转到对应分组
- 🖼️ **必应壁纸背景**：每日自动更新Bing美图为背景
- 🔍 **悬停显示复制按钮**：鼠标悬停消息显示复制按钮
- 🌙 **毛玻璃效果**：卡片背景模糊 + 动态阴影
- 📱 **完全响应式**：自适应移动端、平板、桌面端
- 🔎 **智能搜索框**：搜索对话 + AI推荐 二合一
  - 输入关键词：实时搜索匹配消息
  - 按回车/点按钮：AI智能推荐话术
  - 搜索结果与AI结果并行显示
- 🤖 **AI智能话术推荐**：基于所有历史对话学习
  - 点击AI推荐话术一键复制
  - 请求中/思考中/结果展示完整状态链
  - 3种风格推荐：亲切友好 / 专业正式 / 简洁高效
  - 点击外部区域自动关闭搜索列表

### 🔐 后台管理

- 🧭 **快速导航栏**：顶部6个功能导航，一键直达
- 📁 **分组管理**：添加/编辑/删除分组，带滚动限制
- 💬 **添加多消息会话**：自由添加多条消息，每条可选择发送人
- ⚙️ **页面设置**：自定义页面标题、副标题、前端访问密码
- 🤖 **AI智能设置**：独立AI设置管理面板
  - 功能开关控制
  - 兼容所有OpenAI格式接口（官方/OneAPI/NewAPI/本地Ollama等）
  - 自定义模型名称
  - 自定义系统提示词（AI角色设定）
  - 环境诊断（PHP/CURL/JSON配置检查）
- 🔑 **修改管理员密码**：安全修改后台登录密码
- 🔒 **前端访问控制**：开关控制 + 自定义访问密码
- 📋 **会话列表**：分组折叠、批量删除、编辑/删除单个

### 🛡️ 安全功能

- 🔐 **后台密码登录**：简单密码验证机制
- 🔒 **前端访问密码**：可配置开启，Session验证
- 🚪 **退出访问功能**：已验证用户可手动退出访问状态
- ✋ **编辑权限**：仅后台可修改内容

## 🚀 快速开始

### 环境要求

- PHP 7.0+
- Apache / Nginx
- CURL 扩展（**必需**：用于AI接口调用）
- JSON 扩展
- 支持文件上传
- 支持 Session

### 安装部署

1. **上传文件**到PHP服务器根目录

2. **权限设置**：确保 `chat/` 和 `photos/` 目录有写入权限（程序会自动初始化）

3. **访问首页**：
   ```
   http://your-domain/index.php
   ```

4. **进入后台**：
   ```
   http://your-domain/admin/login.php
   ```
   默认管理员密码：`admin123`

### 🤖 AI智能话术设置

#### 第一步：开启并配置

1. 进入后台 → 🤖 AI设置
2. ✅ 勾选「启用AI推荐话术功能」
3. 配置API参数：

| 设置项 | 示例值 | 说明 |
|--------|--------|------|
| 🌐 API接口地址 | `https://api.openai.com/v1/chat/completions` | **必须带 `/v1/chat/completions` 后缀！** |
| 🤖 模型名称 | `gpt-3.5-turbo` / `mimo-v2-flash` | 根据API提供商填写 |
| 🔑 API Key | `sk-...` | 你的API密钥 |
| 📝 系统提示词 | 话术顾问角色设定 | 自定义AI人格 |

#### 第二步：环境诊断

页面底部自动显示环境检测结果：
```
✅ PHP版本：7.4+
✅ CURL扩展：已启用  ← 这个是AI功能必需！
✅ JSON支持：已启用
✅ allow_url_fopen：开启
```

#### 第三步：前端使用

在首页搜索框：
1. 输入客户问题（如："这个有优惠吗？"）
2. **按回车键** 或 **点击 [🤖 AI推荐] 按钮**
3. AI基于所有历史对话学习，生成3种风格回复
4. 点击任意推荐话术，**一键复制到剪贴板**

## ❓ AI常见问题排查

| 错误现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| **HTTP 401** | API Key错误 | 检查密钥 |
| **HTTP 404** | 接口地址错误 | 确保结尾带 `/v1/chat/completions`！ |
| **HTTP 429** | 触发速率限制 | 减少请求频率 |
| **HTTP 500** | 模型名称错误 | 使用API提供商支持的模型 |
| **CURL连接超时** | 网络问题 | 检查服务器外网访问 / 配置代理 |
| **CURL未启用** | PHP环境问题 | 安装php-curl扩展 |
