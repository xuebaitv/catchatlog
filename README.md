# 💬 对话展示系统

一个功能完善的PHP对话展示系统，模拟微信式左右对话气泡，支持文字和图片显示，包含完整的后台管理功能、分组管理、瀑布流布局和前端访问密码保护。

## ✨ 功能特点

### 🎨 前端展示

- 💬 **微信式气泡布局**：客户消息左对齐，我的消息右对齐
- 🌊 **瀑布流卡片布局**：CSS Columns 实现智能瀑布流，高度自适应
- 🎯 **分组导航栏**：顶部导航快速跳转到对应分组
- 🖼️ **必应壁纸背景**：每日自动更新Bing美图为背景
- 🔍 **悬停显示复制按钮**：鼠标悬停消息显示复制按钮
- 🌙 **毛玻璃效果**：卡片背景模糊 + 动态阴影
- 📱 **完全响应式**：自适应移动端、平板、桌面端

### 🔐 后台管理

- 🧭 **快速导航栏**：顶部5个功能导航，一键直达
- 📁 **分组管理**：添加/编辑/删除分组，带滚动限制
- 💬 **添加多消息会话**：自由添加多条消息，每条可选择发送人
- ⚙️ **页面设置**：自定义页面标题、副标题
- 🔑 **修改管理员密码**：安全修改后台登录密码
- 🔒 **前端访问控制**：开关控制 + 自定义访问密码
- 📋 **会话列表**：分组折叠、批量删除、编辑/删除单个

### 🛡️ 安全功能

- 🔐 **后台密码登录**：简单密码验证机制
- 🔒 **前端访问密码**：可配置开启，Session验证
- 🚪 **退出访问功能**：已验证用户可手动退出访问状态
- ✋ **编辑权限**：仅后台可修改内容

## 🚀 快速开始

### 环境要求

- PHP 7.0+
- Apache / Nginx
- 支持文件上传
- 支持 Session

### 安装部署

1. **上传文件**到PHP服务器根目录

2. **权限设置**：确保 `chat/` 和 `photos/` 目录有写入权限（程序会自动初始化）

3. **访问首页**：
   ```
   http://your-domain/index.php
   ```

4. **进入后台**：
   ```
   http://your-domain/admin/login.php
   ```
   默认管理员密码：`admin123`

## ⚙️ 后台管理功能详解

### 🧭 导航菜单

| 按钮 | 功能 |
|------|------|
| 📁 分组管理 | 管理对话分组 |
| 💬 添加会话 | 添加多消息对话 |
| ⚙️ 页面设置 | 标题、副标题、访问密码 |
| 🔐 修改密码 | 更改管理员登录密码 |

### 📁 分组管理

- ✅ 添加分组：名称 + 描述
- ✅ 编辑已有分组
- ✅ 删除分组（含关联对话）
- ✅ 最多300px高度滚动，防止无限撑大
- ✅ 精美自定义滚动条

### 💬 添加会话

- **默认**：2条消息模板（客户 + 我）
- **自由添加**：点击「+ 添加消息」继续新增
- **每条独立设置**：发送者（客户/我）、文字内容、多张图片
- **选择分组**：可指定所属分组

### ⚙️ 页面设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 🔘 前端访问密码开关 | 开启/关闭首页访问验证 | 关闭 |
| 📝 页面标题 | 首页大标题 | 客户聊天展示 |
| 📝 页面副标题 | 首页小标题 | 真实对话记录展示 |
| 🔑 前端访问密码 | 首页访问验证密码 | view123 |

### 🔐 修改密码

安全三步验证：
1. ✅ 当前密码验证
2. ✅ 新密码 ≥ 4位
3. ✅ 两次输入一致

> 修改成功后自动退出重新登录

### 📋 对话列表

- 📂 **分组折叠**：点击分组名展开/折叠
- ✅ **复选框选择**：单个/全选，批量删除
- ✏️ **编辑**：修改会话内容、发送者、分组
- 🗑️ **删除**：单个删除操作

## 🔒 前端访问控制

### 启用访问密码

1. 进入后台 → ⚙️ 页面设置
2. 开启「启用前端访问密码保护」
3. 设置访问密码（默认：view123）
4. 保存设置立即生效

### 访问流程

```
访问首页 → 密码验证页面 → 输入正确密码 → 正常查看内容
                                 ↳ 错误 → 停留在验证页
```

### 退出访问

已验证用户可点击首页右上角「🚪 退出访问」按钮重新验证。

## 🔧 配置文件说明

**inc/config.php 核心配置：**

```php
// 管理员密码（后台可修改）
define('ADMIN_PASSWORD', 'admin123');

// 路径配置
define('CHAT_DIR', __DIR__ . '/../chat/');
define('PHOTOS_DIR', __DIR__ . '/../photos/');
define('GROUPS_FILE', __DIR__ . '/../chat/groups.json');
define('SETTINGS_FILE', __DIR__ . '/../chat/settings.json');
```

**chat/settings.json 动态设置：**

```json
{
    "page_title": "客户聊天展示",
    "page_subtitle": "真实对话记录展示",
    "access_password_enabled": false,
    "access_password": "view123"
}
```

## 💡 使用技巧

### 1. 添加单条消息对话
> 添加会话 → 添加消息后删除多余消息块 → 保存

### 2. 快速跳转
> 点击顶部导航按钮直达目标区域，带高亮提示

### 3. 批量删除
> 点击分组的「全选」checkbox → 点击批量删除按钮

### 4. 移动端优化
> 分组自动折叠，点击展开查看，对话列表支持横向滚动

### 5. 复制消息内容
> 前端鼠标悬停在任意消息上，右上角显示「复制」按钮

## ⚠️ 注意事项

1. **修改默认密码**：部署后请立即修改后台管理员密码
2. **文件权限**：确保 chat/ 和 photos/ 目录可写
3. **访问密码安全**：仅用于简单访问控制，请勿使用重要密码
4. **删除操作**：删除分组会影响分组关联，不会删除对话文件
5. **浏览器缓存**：设置修改后刷新前台页面生效
