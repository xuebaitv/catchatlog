# 💬 智能对话工作台

一个功能完善的PHP全能工作台，集成微信式对话展示/智能备忘录/交互式思维导图三大核心模块，毛玻璃现代化设计，支持AI智能整理、PWA桌面应用、只读浏览模式等强大特性。

## ✨ 三大核心模块

### 💬 模块一：客服快捷回复系统
微信式气泡对话布局，专为客服人员高效工作设计

- 微信式气泡布局：客户消息左对齐，我的消息右对齐
- 瀑布流卡片布局：CSS Columns 智能瀑布流，高度自适应
- 必应每日壁纸背景 + 毛玻璃特效
- 智能搜索 + AI话术推荐二合一
  - 支持3种风格推荐：亲切友好 / 专业正式 / 简洁高效
  - 兼容所有OpenAI格式接口
- PWA渐进式应用：桌面/手机可安装到主屏，离线缓存
- 紧凑型视图模式：信息密度更高，适合大量对话浏览

### 📝 模块二：智能备忘录
富文本编辑器 + AI自动整理，快速记录并美化内容

- Quill.js 专业富文本编辑器：加粗/斜体/颜色/背景等丰富格式
- 右键+移动端长按弹出快捷操作菜单
- 全屏预览模式：继承备忘录自定义背景色，卡片式沉浸式展示
- 选中文字自动弹出悬浮快捷格式工具栏
- 🤖 AI一键智能整理
  - 自动生成清晰合适的中文标题
  - 使用h1/h2/h3标题、p段落、strong强调、ul/li列表自动排版
  - 所有原始信息100%保留，绝不丢失内容
  - 自定义输入提示词告诉AI怎么优化
- 完全响应式：移动端完美适配

### 🧠 模块三：交互式思维导图
可视化脑图工具，支持自由创建/编辑/缩放/平移浏览，支持AI一键生成超复杂多层级思维导图

- 🤖 **AI文本自动生成思维导图**（全新功能）
  - 一键点击「🤖 AI生成」按钮，弹出美观悬浮输入窗
  - 粘贴任意文本：文章/笔记/大纲/段落均可
  - 智能自动解析，提取主题、子主题、关键点
  - 支持**无限多层级深度嵌套**，轻松生成5-6层以上复杂树状结构
  - 生成后自动保存历史，支持撤销/重做
- 直观节点操作：创建/删除/重命名/移动/复制节点
- 一键✨自动排列，节点智能布局，自动整理美观不重叠
- 🎨 自定义背景设置，多种精美背景可选
- 🎯 一键居中画布，快速回到中心
- 流畅交互：滚轮缩放画布、左键拖动画布
- **只读浏览模式**：无需登录管理员，所有人可自由浏览所有思维导图
  - 侧边栏完整展示思维导图列表
  - 点击任意思维导图立即打开浏览
  - 编辑相关操作自动隐藏，界面干净清爽
  - 输入管理员密码无缝进入编辑模式
- 原子性写入防断电：先写临时文件成功后rename，绝对不会写出0字节损坏JSON文件

## 🚀 快速开始

### 环境要求
- PHP 7.0+
- Apache / Nginx
- CURL 扩展（AI功能必需）
- JSON 扩展
- 支持 Session 和 文件上传

### 安装部署
1. 上传所有文件到PHP服务器
2. 给 `chat/` `photos/` `memo/data/` `mindmap/data/` 目录设置777写入权限
3. 访问各模块入口：
   - 对话首页：`http://your-domain/index.php`
   - 备忘录：`http://your-domain/memo/index.php`
   - 思维导图：`http://your-domain/mindmap/index.php`
4. 后台管理：`http://your-domain/admin/login.php`
   - 默认密码：`admin123`

## 🤖 AI智能功能配置
进入后台管理 → AI设置
- 启用AI功能开关
- 填写兼容OpenAI格式的API接口地址（结尾带/v1/chat/completions）
- 配置API Key、模型名称、自定义系统提示词
- 环境诊断自动检查PHP/CURL/JSON配置状态

所有AI配置自动全局共享，对话/备忘录两个模块复用同一套配置！
